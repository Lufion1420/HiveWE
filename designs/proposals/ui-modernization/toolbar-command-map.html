Ribbon command map (src/main_window/main_ribbon.cpp) to compact toolbar and menus

Menu bar: File, Edit, View, Terrain, Map, Tools. Toolbar groups left to right: File, History, Visibility, Camera, Editors, search field. Palette modes (Terrain, Doodads, Units, Pathing, Regions) live on the existing sidebar mode buttons. Commands that appear in several ribbon tabs (mirror_button) collapse to one place. Shortcuts are the ones wired in hivewe.cpp. Note: HiveWE.ui also gives the Test Map action Ctrl+T, but hivewe.cpp binds Ctrl+T to Wireframe; whether the .ui action is live is unverified, so Test Map is shown without a shortcut.
